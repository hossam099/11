# Dr. Hadeer Mohamed eid Portfolio Website

A responsive personal portfolio website built using **HTML**, **CSS**, and structured for extension using **SASS/SCSS**.  
The project includes multiple sections: Bio, Skills, Media, Projects, Clients, and Contact.


## Features
- Fully responsive layout  
- Sticky header  
- Dark/Light theme toggle  
- Grid-based sections  
- Clean modular structure  
- Ready for SASS integration  
- Organized assets (images, video, icons)


## 🎨 Technologies Used
- **HTML5**
- **CSS3**
- **Custom Properties (CSS Variables)**
- **Grid / Flexbox Layout**
- **Responsive Media Queries**
- **SASS (optional enhancement)**
